# Hamza's docs workspace

Welcome. This is Hamza's docs workspace.

أهلاً. هذه مساحة عمل توثيق حمزة.

## What this repo is for

This repository is the home of the docs site, built with [Mintlify](https://mintlify.com):

- Docs pages, written as MDX
- Site settings in `docs.json`
- A local preview you can start with `mint dev`

## ما الغرض من هذا المستودع

هذا المستودع هو موطن موقع التوثيق، ومبني على [Mintlify](https://mintlify.com):

- صفحات التوثيق مكتوبة بصيغة MDX
- إعدادات الموقع في ملف `docs.json`
- معاينة محلية يمكنك تشغيلها بالأمر `mint dev`
